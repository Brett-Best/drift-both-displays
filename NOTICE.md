This repository contains only independently written loader, build, packaging,
and diagnostic source code. It does not contain Apple's Drift executable,
resources, shaders, artwork, or other Apple-owned files.

The build script reads the copy of Drift already installed by macOS and creates
a local derivative bundle for personal testing. Generated applications and
